ProxyPin — full steps

Liên kết với tool này

  1. Web bấm Xuất ProxyPin package → lưu JSON
  2. Làm các bước dưới (giống video)
  3. ProxyPin → Script → Nhập → chọn JSON từ tool
  4. Start (Play) → mở Free Fire

Package = template + guide. Script aim thương mại (Delta) là file/key riêng — tool không ship.

1 — Cài app

  1. App Store → ProxyPin - Open Source Capture

2 — Cài đặt proxy

  1. Tab bánh răng
  2. Bật SOCKS5 + HTTP/2
  3. Vào Proxy HTTPS

3 — Chứng chỉ CA

  1. Download Certificate
  2. Cài đặt chung → Quản lý VPN & thiết bị → cài ProxyPin CA
  3. Giới thiệu → Cài đặt tin cậy chứng nhận → bật ProxyPin CA

4 — Import từ tool

  1. Cấu hình → Script → Bật Script → Nhập
  2. Chọn JSON xuất từ web

5 — Chạy

  1. All Requests → Play (VPN)
  2. Mở Free Fire
  3. Menu/key bên thứ 3 (nếu có) — không thuộc tool
