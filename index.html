ProxyPin (dễ trên iOS 27.2 stock)

  1. Cài ProxyPin từ App Store
  2. Web bấm Xuất ProxyPin config → lưu JSON
  3. ProxyPin → Scripts/Import → chọn JSON
  4. Bật HTTPS + trust cert nếu cần → Start
  5. Mở Free Fire (template web chỉ là khung; script aim thật cần config nguồn khác nếu template chưa đủ)
